# Changelog

All notable changes to this project will be documented in this file.

## [0.3.0] - 2026-11-09

### Added

- Added `DataTable`, a neutral shell for column-driven rows, custom cell renderers and empty states.
- Added checks for markdown-linting and commitlint, including GitHub workflows.

## [0.2.0] - 2026-10-26

- Added new components `DropdownMenu`, `Alert`, `EmptyState`, `Skeleton`, `Pagination`.

## [0.1.0] - 2026-10-09

### Added

- Added initial library with selected components and a light theme.
